# 指令包索引

> 按包名排序。安装：`AI:text-cli;install,<包名>`

| 包名 | 指令 | 描述 | 示例 |
|------|------|------|------|
| ai-inference | `AI;推理,<提示词>[,<模式>]` | 文本推理，多模式模型选择 | `AI;推理,法国的首都是哪,auto` |
| ai-inference | `AI;视觉,<提示词>,<图片>[,<模式>]` | 视觉推理（URL/base64/缓存） | `AI;视觉,描述图片,https://...,auto` |
| embed | `语义;编码,<文本>[,<模式>]` | 文本转向量（256-2048 维） | `语义;编码,威海冬天海风很大` |
| embed | `语义;相似,<文本A>,<文本B>[,<模式>]` | 计算语义相似度（0-1） | `语义;相似,威海冷,威海冬天海风大` |
| embed | `语义;匹配,<查询>,<候选1>,<候选2>,...` | 多候选语义匹配 | `语义;匹配,今天天气,晴天;下雨;多云` |
| geo-grid | `地理网格;六边形网格,<经度>,<纬度>[,<分辨率>]` | 坐标 → H3 六边形格子 | `地理网格;六边形网格,122.1,37.5,8` |
| geo-grid | `地理网格;中心点,<lon1>,<lat1>,<lon2>,<lat2>` | 两点地理中心点 | `地理网格;中心点,122,37,122.2,37.2` |
| geo-grid | `地理网格;缩放计算,<lon1>,<lat1>,<lon2>,<lat2>` | 两点最佳地图缩放 | `地理网格;缩放计算,122,37,122.2,37.2` |
| geo-grid | `地理网格;距离转缩放,<米>` | 距离 → 缩放级别 | `地理网格;距离转缩放,5000` |
| geo-grid | `地理网格;H3分辨率,<米>` | 距离 → H3 分辨率 | `地理网格;H3分辨率,500` |
| geo-grid | `地理网格;半径边界框,<经度>,<纬度>,<米>` | 中心+半径 → 边界框 | `地理网格;半径边界框,122.1,37.5,1000` |
| geo-grid | `地理网格;偏移,<经度>,<纬度>,<方位角>,<km>` | 原点+方位+距离 → 目标 | `地理网格;偏移,122.1,37.5,90,10` |
| geo-grid | `地理网格;路线解析,<JSON>,<来源>,<模式>` | 路线JSON → 有名道路坐标 | `地理网格;路线解析,{...},bd-map,tail` |
| image | `图片;信息,<路径>` | 图片尺寸/格式/EXIF | `图片;信息,/tmp/photo.jpg` |
| image | `图片;编码,<路径>[,<最大尺寸>]` | Base64 编码存缓存 | `图片;编码,/tmp/photo.jpg` |
| image | `图片;转换,<输入>,<格式>[,<质量>]` | 格式转换（png/jpg/webp/bmp） | `图片;转换,/tmp/a.jpg,png,90` |
| image | `图片;缩放,<输入>,<宽>,<高>` | 等比缩放 | `图片;缩放,/tmp/a.jpg,800,600` |
| key | `密钥;注册,<服务名>,<值>[,<值2>],<类型>` | 注册密钥（单/双凭据） | `密钥;注册,my-api,sk-xxx,api_key` |
| key | `密钥;撤销,<服务名>` | 撤销密钥 | `密钥;撤销,my-api` |
| key | `密钥;列表` | 列出所有已注册密钥 | `密钥;列表` |
| key | `密钥;配额追踪,<服务名>[,<目标>,...]` | 设置/清除配额追踪 | `密钥;配额追踪,my-api,ai:infer` |
| key | `密钥;导出加密,<服务名>` | XOR加密导出凭据 | `密钥;导出加密,my-api` |
| openclaw-cmd | `openclaw;网关状态` | 查看 OpenClaw 网关状态 | `openclaw;网关状态` |
| openclaw-cmd | `openclaw;会话列表` | 列出 OpenClaw 会话 | `openclaw;会话列表` |
| path-str | `路径字符串;模板,<模板>[,键=值,...]` | 模板替换 `{key}` `{0}` | `路径字符串;模板,你好 {name},name=世界` |
| path-str | `路径字符串;切分,'<字符串>','<分隔符>'` | 切分字符串为数组 | `路径字符串;切分,'a;b;c',';'` |
| path-str | `路径字符串;合并,'<JSON数组>','<分隔符>'` | JSON数组 → 分隔字符串 | `路径字符串;合并,'["a","b"]',';'` |
| quota-manage | `配额;注册,<目标>,<周期>,<上限>` | 注册配额规则 | `配额;注册,my-api,day,100` |
| quota-manage | `配额;检查,<目标>[,<数量>]` | 检查并消耗配额 | `配额;检查,my-api` |
| quota-manage | `配额;列表` | 列出所有配额 | `配额;列表` |
| quota-manage | `配额;重置,<目标>` | 手动归零计数器 | `配额;重置,my-api` |
| quota-manage | `配额;注销,<目标>` | 移除配额规则 | `配额;注销,my-api` |
| task-manager | `任务;状态,<任务ID>` | 查询异步任务状态 | `任务;状态,abc123` |
| task-manager | `任务;结果,<任务ID>` | 获取任务结果 | `任务;结果,abc123` |
| task-manager | `任务;列表` | 列出所有任务 | `任务;列表` |
| task-manager | `任务;追踪,<任务ID>` | 获取缓存追踪键 | `任务;追踪,abc123` |
| task-manager | `任务;取消,<任务ID>` | 取消任务 | `任务;取消,abc123` |
| template | `模板;列表` | 列出所有提示词模板 | `模板;列表` |
| template | `模板;使用,<ID>[,键=值,...]` | 渲染模板并替换占位符 | `模板;使用,默认,地点=威海` |
| tideweather | `天气;查询,<日期>,<城市>` | 天气预报（双源降级） | `天气;查询,明天,威海` |
