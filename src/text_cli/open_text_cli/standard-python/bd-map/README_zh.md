# 百度地图服务

百度地图 HTTP API 封装：地理编码、IP 定位、路线规划、坐标转换、静态图。

## 安装

```
AI:text-cli;install,bd-map
```

## 依赖

- **运行时模块**：`text_cli_modules/key/`
- **凭据**：百度地图 API 密钥（ak），通过 `AI:key;register,bd,<ak>,api_key` 注册

## 指令

| 指令 | 说明 |
|------|------|
| `百度地图;地理编码,<地址>` | 地址 → WGS84 坐标 |
| `百度地图;IP定位,<IP>[,<坐标系>]` | IP → 城市 |
| `百度地图;路线规划,<起点>,<终点>[,<出行方式>,<地址模式>]` | 驾车/公交/步行/骑行路线 |
| `百度地图;静态图,<经度>,<纬度>[,<缩放>,<尺寸>,<标注>,<标签>,<折线>]` | 静态地图（base64 PNG） |
| `百度地图;坐标转换,<经度>,<纬度>,<模式>` | BD09/GCJ02/WGS84 互转 |

## 示例

```
AI:百度地图;地理编码,北京市海淀区
AI:百度地图;路线规划,北京,上海,driving,1
AI:百度地图;静态图,116.404,39.915,14,600
AI:百度地图;坐标转换,116.404,39.915,2
```

## 架构

```
bd-map/
├── schema.json

└── README_CN.md
```
