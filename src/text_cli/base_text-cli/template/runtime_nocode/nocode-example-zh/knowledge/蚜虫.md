# 蚜虫

## 症状
- 嫩芽、嫩叶、花苞上聚着一群芝麻大小的虫子
- 有绿的、黑的、黄的，密密麻麻挤在一起
- 被咬的嫩叶会卷起来、变形
- 叶面上有黏糊糊的透明液体（蚜虫的排泄物，叫"蜜露"）
- 有蜜露的地方过几天可能会长黑霉（煤污病）

## 多发条件
- 春天新芽萌发期（3-5 月最严重）
- 不通风的阳台或室内
- 施氮肥太多，叶子太嫩
- 附近有蚂蚁——蚂蚁会"放牧"蚜虫，把它们搬到嫩芽上

## 容易误判的情况
- 红蜘蛛（叶螨）：也会让叶子卷曲发黄，但叶子背面有极细的蛛网，翻过来用放大镜能看到针尖大的红点——跑得很快，蚜虫是趴着不动的
- 白粉虱：也是白色小虫子，但一碰就飞，不会密密麻麻挤在嫩芽上

## 处理方案
1. 数量少（十几个以内）：
   a. 拿棉签蘸酒精，一个个擦掉
   b. 或者对着水龙头冲（水压不要太大，别把嫩芽冲断了）
2. 数量多：
   a. 洗衣粉水：一小撮洗衣粉兑一升水，喷叶子正反面（避开中午喷，傍晚喷）
   b. 辣椒水：5 个干辣椒煮 500ml 水 15 分钟，过滤后喷
   c. 吡虫啉：花市买，按说明兑水喷一次，三天蚜虫就干了
3. 喷完第二天检查，如果还有活的重喷一次
4. 如果蚂蚁多，在花盆周围撒一圈蚂蚁药——断掉蚂蚁的"搬运服务"

## 我的血泪教训
发现蚜虫第一天没当回事，想着"几个小虫子而已"。一周后整个阳台的月季嫩芽上全是——从一盆扩散到了七盆。
