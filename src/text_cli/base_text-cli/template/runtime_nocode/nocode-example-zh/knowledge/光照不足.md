# 光照不足

## 症状
- 叶片颜色变浅，从深绿变成浅绿甚至黄绿
- 枝条细长、节间距变长（"徒长"），像一根细筷子顶几片小叶子
- 开花植物：花苞少或者完全不开花
- 多肉植物：摊大饼——本来紧凑的莲座形摊开像一张饼
- 叶子向光的方向歪着长（趋光性明显）

## 多发条件
- 放在北阳台或者窗户朝北的房间
- 放在客厅中间，离窗户超过 3 米
- 窗外有大树或高楼挡住阳光
- 冬天日照时间短
- 玻璃太久没擦了（灰尘挡光很厉害）

## 容易误判的情况
- 浇水太多也会让新枝条细长——区别：水多+光照够=也徒长，但叶片颜色不会变浅
- 缺肥：老叶先黄，新叶可能正常

## 处理方案
1. 移到光照最好的位置——朝南窗户旁 30cm 以内
2. 如果家里实在没光，考虑补光灯：
   - 普通 LED 灯泡（白光 6500K）距离植物 10-15cm，每天照 8 小时
   - 不用买专门的植物灯——普通白光 LED 够用了
3. 已经徒长的枝条：剪掉——它不会变粗，留着只浪费养分
4. 适应期：从暗处移到亮处要循序渐进，先放在散射光处 3-5 天，再移到直射光处（否则会晒伤）
5. 定期转盆——一周转 90 度，不然会长偏

## 我的血泪教训
在威海（纬度 37°）养了一盆茉莉，放在客厅茶几上，离窗户两米多。三个月后它长成了一根 60cm 的绿色筷子，一片叶子都没有——全掉光了。移到窗户边剪掉重来，两个月后恢复了。
