# 白粉病

## 症状
- 叶片上有一层白色粉末，像撒了面粉
- 通常从老叶开始，慢慢蔓延到新叶和花苞
- 严重时叶片卷曲、变硬、发脆
- 新长出来的嫩叶会扭曲变形
- 用手一抹白色的粉末能擦掉，但过两天又长出来

## 多发条件
- 白天热晚上凉、湿度大的季节（春秋换季最厉害）
- 通风差——阳台封闭、室内角落
- 植株太密，叶子挤在一起不通风
- 盆土偏干时更容易中招（和根腐病相反：干着反而得白粉）

## 容易误判的情况
- 某些多肉和仙人掌天生有白粉保护层——那是品种特征，擦不掉也不复发
- 灰尘——擦掉后不会再长

## 处理方案
1. 早期（几片叶子）：
   a. 直接剪掉有白粉的叶子，包起来扔掉（不要丢在花盆里）
   b. 把花盆移到通风更好的位置
2. 蔓延期：
   a. 小苏打水：一汤匙小苏打 + 一升水 + 几滴洗洁精（帮助附着），喷叶子正反面，每三天一次
   b. 牛奶水：牛奶和水的比例 1:9，喷叶子正反面，晒太阳（紫外线激活牛奶的杀菌作用）
   c. 多菌灵或百菌清：花市买，按说明用
3. 剪掉过密的枝条和小侧芽，让植株通风透光
4. 以后浇水时不要淋到叶子上（叶面有水 + 不通风 = 白粉温床）

## 我的血泪教训
紫薇得白粉病，我以为是品种自带的白粉（有些紫薇确实有白粉品种）。拖了两周没处理，最后整棵叶子掉光了。后来才知道——健康的紫薇叶是干净绿色的，有白粉就是病了。
