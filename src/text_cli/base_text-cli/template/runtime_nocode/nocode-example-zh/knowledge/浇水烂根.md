# 浇水烂根（非病菌型）

## 症状
- 整株打蔫，但土是湿的
- 叶片没有黄斑，整片软塌塌下垂
- 土面可能有绿色苔藓或白色盐碱结晶
- 根没烂到发黑，但软趴趴的像煮过的面条

## 多发条件
- 新手最常见的错误——怕花渴，天天浇
- 用了没有排水孔的装饰盆（套盆）
- 冬天室温低但还按夏天频率浇
- 出差前猛浇一次，回来发现泡烂了

## 容易误判的情况
- 根腐病：茎基部发黑，有臭味，是真菌感染；浇水烂根茎基部不黑，没异味，纯粹是水多憋的
- 缺水：叶子也打蔫，但土是干的，浇水后几小时就恢复

## 处理方案
1. 立刻停止浇水
2. 把花盆倾斜 45 度，让多余的水从盆底流出来
3. 用筷子在土里戳几个洞（不要戳到根），加速蒸发
4. 放到通风处，但不要晒太阳（叶子已经蔫了，暴晒会脱水死掉）
5. 三天后再摸土，等表土干了 2-3cm 再考虑浇
6. 如果一周还没好转，可能要脱盆晾根，去掉烂掉的软根重新种

## 经验之谈
养花第一年，我浇死的比旱死的多 10 倍。"干透浇透"四个字，关键是"干透"——你要学会相信花比人耐旱。

## 通用浇水判断法
手指插进土里两个指节（约 2cm），感觉干了才浇。
竹签法：插一根烧烤竹签到盆底，拔出来看——湿的不浇，干的浇。
掂盆法：浇水前后各掂一次重量，以后凭重量判断要不要浇。
