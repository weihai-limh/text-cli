# 根腐病

## 症状
- 叶片从下往上发黄，一碰就掉
- 靠近土面的茎变黑、变软，用手捏有湿烂感
- 土面有白色或灰色霉层
- 拔出来看，根是褐色或黑色的，一扯就断（健康根是白色或浅黄的）
- 土闻起来有腥臭味

## 多发条件
- 连续阴雨天超过 3 天
- 盆底没有排水孔，或者孔被堵了
- 用的土太细（园土比例超过 70%）
- 冬天室内通风差，浇水后一周土还是湿的

## 容易误判的情况
- 晒伤：也是叶片发黄，但黄斑在叶尖和叶缘，不会掉叶
- 自然老化：底部老叶慢慢黄，不是突然大量掉

## 处理方案
1. 立刻停水，把花盆移到通风处（不要暴晒）
2. 如果茎已经发黑超过 2cm，基本救不回来了
3. 如果能救：
   a. 脱盆，把烂根全部剪掉（剪到看见白色截面为止）
   b. 用多菌灵 1:1000 泡根 15 分钟
   c. 换新土（泥炭土：珍珠岩 = 7:3），旧土扔掉不要重复用
   d. 种回去后放在散射光处，等土干透再浇第一次水
4. 以后浇水原则：手指插进土里 2cm 感觉干了再浇

## 我的血泪教训
去年夏天连续下雨，我一盆养了三年的月季烂根了。当时不懂，以为是缺水，又浇了一次——第二天茎全黑了。从此我记住：叶子蔫 + 土是湿的 = 不是缺水，是烂根。
