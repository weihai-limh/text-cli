# 黄叶病（缺铁性）

## 症状
- 新长出来的嫩叶发黄，但叶脉还是绿的（像绿色网格套在黄布上）
- 老叶颜色正常
- 植株整体长得慢，新芽细小

## 多发条件
- 长期用自来水浇花（北方水偏碱）
- 土用了超过一年没换
- 只施氮磷钾复合肥，没用过微量元素肥
- 种在喜酸植物上（栀子、杜鹃、茉莉、茶花最容易出这个问题）

## 容易误判的情况
- 缺氮：也是黄，但是从老叶开始黄，整片均匀黄
- 自然落叶：入秋后老叶黄了掉，新叶正常

## 处理方案
1. 去花市买"硫酸亚铁"（一两块钱一小包）
2. 按 1:1000 兑水（一克兑一升水，大概一个可乐瓶盖兑一桶水）
3. 浇透一次，三天后新叶颜色会好转
4. 以后每月浇一次稀释的米醋水（一汤匙醋兑一升水）保持土偏酸
5. 长期方案：换土时用松针土或者泥炭土，自带酸性

## 我的血泪教训
养了三盆栀子花，两年没换土没调酸，最后三盆一起黄——以为是传染病，结果是土的问题。
