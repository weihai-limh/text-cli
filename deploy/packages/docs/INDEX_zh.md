# open_text_cli 运行时分类导航

> 本文件是 `open_text_cli/` 的**运行时分类入口**。具体每个包的安装步骤、指令表格与使用示例见各运行时目录内的 `INDEX_zh.md` 及包内 `README_zh.md`。

## 一、本目录说明

- **定位**：随 text-cli 运行时分发的 **MIT 起步包示例集**（非模板库）。按运行时类型和语言组织。
- **分发**：具体分发由 `scripts/build-all.py` 从本目录全量复制到 `deploy/packages/` 完成。
- **包清单**：本文件只列运行时目录，不录包。各运行时目录内的 `docs/INDEX_zh.md` 维护该运行时下的包清单。

## 二、运行时分类

| 运行时目录 | 类型 | 语言 |  说明 |
|-----------|------|------|:---:|------|
| [standard-python/](standard-python/) | 标准运行时 | Python |  Python 标准运行时指令包，可 `install` 即用的基础工具 |
| [base-js/](base-js/) | 旁路运行时 | JavaScript | JS 运行时指令包 |

## 三、版本与协议说明

- **版本号规则**：首发版本统一为 `0.1.1`（Semver）。本目录不含版本子目录，包根即最新镜像。
- **MIT 协议**：本集合统一采用 MIT 许可证——可自由使用、修改、再分发，仅需保留版权与许可声明。与 text-cli 引擎许可证一致，可随运行时公开分发。
- **内容来源**：本目录各包为 `text-cli-package/releases/` 对应制品的干净副本（已剥离隐私数据），仅保留注释与文档，不含 `DESIGN.md` / `.dev` / 测试脚本。
