- **定位**：JS 旁路运行时指令包集合。与 `standard-python/` 平级，按运行时类型和语言组织。
- **运行时**：旁路运行时（JavaScript），不要求实现标准运行时的全部 9 项协议机制。
- **状态**：当前无包。`web-utils`（原 CloudBase SCF 旁路运行时示例包）已移出，本目录为多语言扩展预留。
