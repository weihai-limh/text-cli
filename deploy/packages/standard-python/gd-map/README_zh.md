# 高德地图服务

高德地图 HTTP API 封装：地理编码、逆地理编码、静态图、多边形 POI 搜索。

## 安装

```
AI:text-cli;install,gd-map
```

## 依赖

- **运行时模块**：`text_cli_modules/key/`
- **凭据**：高德地图 API 密钥对（key + secret），通过 `AI:key;register,gd,<key>,<secret>,amap` 注册

## 指令

| 指令 | 说明 |
|------|------|
| `高德地图;地理编码,<地址>` | 地址 → 坐标 |
| `高德地图;逆地理编码,<经度>,<纬度>[,<POI类型>,<半径>]` | 坐标 → 地址（含周边 POI） |
| `高德地图;静态图,<经度>,<纬度>[,<缩放>,<尺寸>,<标注>,<折线>]` | 静态地图（base64 PNG） |
| `高德地图;搜索,<关键词>,<多边形>` | 多边形区域 POI 搜索 |

## 示例

```
AI:高德地图;地理编码,北京市朝阳区
AI:高德地图;逆地理编码,116.397,39.908,商务写字楼,1000
AI:高德地图;静态图,116.397,39.908,14,600
AI:高德地图;搜索,餐厅,116.3,39.9;116.5,39.9;116.5,40.0;116.3,40.0
```

## 架构

```
gd-map/
├── schema.json
├── handler.py
└── README_CN.md
```

handler 通过 `key_registry` 获取高德 key + secret，MD5 签名认证后调用高德地图 WebService API。
